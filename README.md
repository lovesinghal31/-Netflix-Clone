# -Netflix-Clone
Landing page clone of Netflix.

## Run locally
This project is static HTML/CSS/JS.

1. Clone the repository.
2. Open `/home/runner/work/-Netflix-Clone/-Netflix-Clone/index.html` in a browser.

You can also serve it from the repository root with a simple static server (for example, `python3 -m http.server`) and then visit `http://localhost:8000`.
